Script 98 primary data
The V1 dashboard stores the exact 80-row Script 98 JSON result array in its JavaScript.
Copy the existing file Strait_of_Hormuz_Interactive_Simulation_Dashboard.html into this folder
and rename it v1_dashboard.html, then run:
    python scripts/extract_v1_data.py
The resulting script98_primary.csv is extracted verbatim from the V1 embedded data.
No simulation is rerun and no values are synthesized.
